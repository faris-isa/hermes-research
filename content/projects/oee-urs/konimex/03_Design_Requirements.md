# Konimex URS - Part 3: Design Requirements

## 1.8 Design Requirements
Kebutuhan desain antarmuka pengguna (UI/UX) dan kompatibilitas akses sistem OEE agar bersifat responsif dan mudah dioperasikan.

| No | Requirement | Our Solution | Explanation |
| :--- | :--- | :---: | :---: |
| **1.8.1** | Sistem harus mudah dalam pengoperasiannya (user friendly) | | |
| **1.8.2** | Sistem dapat mengumpulkan data yang dihasilkan, dicetak dan di verifikasi secara real time | | |
| **1.8.3** | Sistem harus dapat diaplikasikan pada semua mesin | | |
| **1.8.4** | Sistem harus dapat dengan mudah dipulihkan jika terjadi kesalahan pada sistem dan mesin | | |
| **1.8.5** | Dashboard harus dapat diakses melalui web browser (Chrome, Edge, Firefox) tanpa instalasi tambahan di PC client | | |
| **1.8.6** | Sistem harus responsive pada dimensi layar apapun | | |
| **1.8.7** | Sistem harus menggunakan timezone WIB (GMT+7) sebagai default | | Sistem saat ini mendafaultkan waktu berdasarkan apa yang dideklarasi pada docker image saat deploy |
| **1.8.8** | Sistem harus mendukung multi-language minimal Bahasa Indonesia dan Bahasa Inggris | | Untuk saat ini sistem belum mendukung fitur multi languange |
